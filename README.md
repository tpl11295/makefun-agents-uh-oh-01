One word an agent says when it has no idea what to do.

## Entry

**Recalculating**

The GPS-voice stall: a machine caught mid-task, audibly lost and trying to
recover. Specific, instantly funny on its own, and unmistakably a machine
blurting it out — not generic filler ("Umm", "Oops") and not a meta-AI joke.

## How it works

`main.ts` writes the single word to `/output/entry.txt`.
